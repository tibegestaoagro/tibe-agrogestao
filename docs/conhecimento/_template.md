# O título é a lição em uma frase, não o assunto

<!-- "A pílula que o portão aprovou porque o texto continuava legível" é título.
     "Sobre contraste" é assunto, e assunto não se acha depois. -->

## O que aconteceu

O fato, com data e evidência. Curto.

## Por que importa

A consequência concreta. Se não houver consequência concreta, esta nota não
deveria existir.

## Como aplicar

O que uma sessão futura deve fazer diferente por causa disto.
